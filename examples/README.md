# Examples

Artifacts generated by OpenDesign runs on this machine, kept as references.

## netflix-homepage-clone.html

Generated 2026-09-06 via the Hermes runtime (`kilocode:minimax/m3` through a
local gateway chain), then hand-tuned with a motion pass:

- Netflix "N" logo intro (scale-in over black, lifts away)
- Ken-burns drift on the hero billboard (26s)
- Staggered hero entrance (tag → title → meta → desc → actions)
- Top-nav fade-down on load
- IntersectionObserver scroll-reveal cascade on carousel rows
- Billboard pager auto-advance every 8s
- `prefers-reduced-motion` disables all of the above

Single self-contained HTML file — open directly in a browser.
Render proof: `netflix-homepage-clone.png`.
